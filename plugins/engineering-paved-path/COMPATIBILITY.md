# Compatibility

Minimum Claude Code version: **2.1.110**, aligned with the other plugins in this marketplace.
This plugin has no dependencies of its own and contains no hooks, agents or scripts.

## Known limits

- Skills are guidance for common stacks (React, Next.js, Fastify, Drizzle, PostgreSQL, Zod,
  TypeScript). They do not detect your stack; an agent loads the ones a plan step names.
- `security` is written around React, Express, MongoDB and JWT examples; apply the principles to
  your stack.
